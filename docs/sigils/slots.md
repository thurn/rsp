# Sigil slots

Every slot in the sigil pool, filled during the waves of the orchestration plan in [skeleton.md](../skeleton.md#appendix-subagent-orchestration-plan). Each row gives the slot's code, rarity, fixed price, slot type, the archetypes it serves, its mechanic family and assigned variation from [mechanics.md](../mechanics.md), its intended timing window from [rules-text.md](../rules-text.md), its role and scoring channel, and a one-line brief. The Signposts column names the accepted wave 1 signposts each slot supports; Gray rows name one only when they clearly feed it. Seeded slots name the sigil that fills them.

Role tags: `rule setter` marks global rule setters, `opponent-facing` marks opponent-facing interaction, and `stat stick` marks sigils intended to change no decision.
